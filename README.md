# Tetris_AI


This project is a Python-based Tetris game that uses an AI agent to play the game automatically. The program includes game logic, AI decision-making, metrics tracking, and tests.

## Main Features

- Playable Tetris game built in Python
- AI agent that chooses moves
- Game folder for the Tetris rules and display
- AI folder for decision-making logic
- Metrics folder for tracking performance
- Tests folder for checking code behavior
